# 应用内 PDF 错题导入：审核与实施记录

日期：2026-10-06。首版范围：Mac 桌面版、离线、用户提供的两份资料、原生红色 Ink / StrikeOut 批注。

## 审核结论

原方向可实施。旧页面只消费外部 Python 脚本生成的暂存数据，没有选择 PDF 和启动识别的入口；脚本还固定使用 book4，而既有发布题库是 book005。截图中的终端提示属于旧工具链，不能直接在 App 内完成操作。

需要补充的核心事项已纳入实现：

- 用资料内容指纹区分高数与线代，分别适配版式；新增原生批注、更改文件名不改变资料身份。未知 PDF 明确拒绝自动裁题。
- 按题目位置生成稳定来源标识，按书本命名题目 ID；不使用“第几个被红笔圈中的题目”作为 ID，防止补标后错配 FSRS。
- 检查下一道题和章节标题的边界，跨页保留题干及解析；超过可确认范围的题目跳过。
- 高数彩色方法框可能与题干框混淆，增加框后解析标记校验。解析区笔记和跨题笔迹不自动当成题干。
- 新增独立 SQLite 导入表及批次图片目录，旧 questions.json、截图题和旧 FSRS 不随导入改写。
- SQLite 事务保存批次，写入前生成完整数据库快照；取消或失败的识别不提交批次。
- 支持按批撤销；任一题目产生复习记录后，批次永久锁定，复习重置也不解除锁定。
- 移除启动时的自动孤儿记录清理；等待当前书本的题库与复习数据都就绪才同步，并防止旧书本异步结果覆盖新书本。
- 应用启动只补齐缺失的资源，不覆盖用户已有题目文件和图片。
- 独立导出/恢复 PDF 导入题库，包含图片校验值、批次与思路；复习记录继续使用 JSON 备份，恢复前另做 SQLite 快照。
- 识别器打包进 App，不要求使用者安装 Python。保留原 Tauri 依赖版本，新增文件选择插件使用兼容版本。
- Mac 资源配置使用明确的路径映射；桌面构建从生成的 dist 中排除重复题库副本，题库通过原生资源读取，源 public 和用户数据保持原样。

旧 HANDOFF_PDF_IMPORT.md 中的“231 道”不符合当前仓库实际数据；public/books/book005/data/questions.json 实际有 172 道，本次未改写该文件。

## 使用步骤

1. 打开新 Mac 桌面版的「PDF导入」，选择已保存批注的 PDF。
2. 选择资料对应的书本。线代没有对应书本时，可以在页面填写名称并新建；高数建议使用现有 book005。首次有效导入后固定绑定。
3. 点击「识别并预览」。可以切换页面，识别完成后返回预览，逐题查看题干、解析及整页，勾选需要的题目。点击「确认加入题库」才保存到任务开始时选定的书本。取消预览不添加题目。未确认的预览不随 App 重启恢复，重启后需要重新识别。
4. 查看新增、重复、跳过数量及原因。重复题目保持原记录，不自动覆盖旧解析。
5. 未开始复习的新增批次可在导入记录中确认撤销。撤销不删除恢复用图片；全部新增题目撤销后，可重新选择资料绑定正确书本。
6. 「备份」中分别保存 PDF 导入题库的 .mathloop 文件与复习 JSON。PDF 备份只恢复至同一 bookId，不包含旧静态题库或 IndexedDB 截图题，也不等于整应用备份。

## 识别边界

不使用云端模型，不上传 PDF；数学公式保留为图像，不转换成可编辑文本。扫描版的题号显示为页内题框序号，章节暂标记为「PDF导入」，避免猜错目录。识别规则不承诺覆盖任意教材；首版只支持内容指纹已核对的这两份 PDF，不支持扁平化到扫描图中的红笔。

答案区至下一题或下一章节为界，最多追踪至题干起始页之后两页；无法确认解答起点/终点时保留原资料、跳过导入。用户可在源文件继续补标，再次导入仅追加新题。旧手工截图没有 PDF 来源坐标，无法保证与新 PDF 裁题自动去重。

## 第二轮：预览、定位与保存思路

- 识别线程只生成暂存预览；原生状态保留待确认的资料、目标书本和候选。预览确认及取消由独立命令完成。确认期间禁用取消，事务保存与导入前快照沿用原机制。
- 可逐题查看题干、解析、来源整页，选择全选、全不选或单题勾选；在同一次预览中切换页面保留选择。未勾选的题目及其独占图片不写入批次。
- 新候选增加印刷页码、裁切图对应 PDF 页码、完整页图片及映射。线代直接读取原生页脚；核对 PDF 第 5–108 页的页脚均为 PDF 页码减 4，第 109 页没有数字页脚，保持未识别。高数使用这个已核对指纹资料的固定正文偏移 13，不应用到其他 PDF。
- 当前已导入 88 道线代题目，不执行重导入或数据库迁移；加载时补充书本页码，保留题目 ID、图片引用、复习卡片、历史和思路。旧 importVersion 3 题目按需从经过指纹核对的源 PDF 读取整页并缓存，原 PDF 移动后需放回原位置；importVersion 4 的整页在批次中保存，随 .mathloop 备份一起导出和恢复。
- 原静态高数题库优先读取已有 pdfSource.fullImage，保留原 pages 目录回退。题目详情、复习和导入预览都可查看整页；跨页裁切对应各自原页。旧版缺少逐图页码时，优先使用明确的首尾页；解析中间页无法确认时不显示错误的整页入口。整页弹窗使用 portal，避免玻璃卡片的 CSS 滤镜限制其覆盖范围。

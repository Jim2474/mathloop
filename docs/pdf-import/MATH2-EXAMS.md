# 数学二真题与独立答案导入

本机 Mac 桌面版在原 PDF 导入流程中增加了数学二套卷和独立答案目录。原始 PDF 始终只读，公式与批注以源图像保留。当前资料规则适用于已核对内容指纹的 52 页 2010—2026 年数学二套卷及配套的 17 份解析，不是任意 PDF 通用识别器。

## 使用

1. 在「PDF导入」选择套卷，再选择保存解析 PDF 的文件夹。
2. 检查 2010—2026 年解析的匹配状态。同年存在两个有效副本时提示冲突；无法验证的版本不猜配。文件改名不会改变内容所属年份。
3. 首次新建「数学二真题错题」，以后自动使用同一个课本。识别完成后逐题查看题干、解析、来源整页和年份题号，再选择入库。
4. 后续保存新批注，再选同一套卷和答案目录识别。按“套卷内容指纹＋年份＋题号”追加；旧题、旧答案、思路和复习进度不会被重写。

红色斜线与叉号按题号区域选题，同一题的多条笔迹合并。正文划线不另建题，孤立小点忽略；标记小问仍保留整题和整题解析，已核对的小问位置会显示具体编号。边界不明或缺少解析会明确列入待核对项。

## 来源和兼容

可选 `exam` 元数据记录年份、科目、题号、标记小问。`pdfSource.questionPageRefs/answerPageRefs` 分别与题干/答案裁切图一一对应，保存来源路径、内容指纹、真实 PDF 页码及 `pageImages` 下标。两份 PDF 页码相同仍能分别打开正确的整页；图片随批次保存，原 PDF 移动后已导入整页仍可读。

`pageImages` 继续由既有批次校验、路径重写、导出和恢复流程管理。带多来源引用的题库导出为 version 2；新版同时读取 version 1 和 version 2，旧题目不迁移、不重写。仅未产生复习记录的批次可撤销，复习后的锁定继续保留。

识别目录 `math2_catalog.json` 的坐标以页面正向渲染后的归一化位置表示；它包括 OCR 初始定位、页面空白间隔调整及人工核查修正。OCR 不作为公式或答案正文。新增模块和目录文件均纳入 worker 构建签名。

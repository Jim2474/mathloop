## 无答案题目的存储

- `answerMeta.hasAnswer=false`、`answerImage=null`、`answerImages=[]`。
- 原生提交与备份恢复只在明确无答案且引用一致时接受空答案列表。
- 有答案的原批次仍要求非空答案图片及一致的单图引用。
- 预览、题目详情及复习明确显示原书未提供答案；思路保存及评分沿用现有机制。
- 题目 ID 由资料指纹、题号及书本 ID 决定，重复识别不覆盖原题或复习记录。

## 启动后题库入口丢失的修复（0.2.2）

用户打开 0.2.1 后，新题库未显示。只读核对发现 19 道题、批次和图片均在，
但 `book-registry` 不再包含新书。数据库没有 `migration-version`，也没有旧格式
`openclaw-review-state`，因此每次 bootstrap 都执行 v1 迁移，其最后一步无条件
把列表替换成 default，随后仅恢复内置书本。该旧逻辑会隐藏所有新增的原生题库。

修复为仅初始化空列表，已存在的书本列表保持原样。不补写迁移版本，避免触发
无关迁移改写已有学习记录。0.2.2 更新前重新保存当前数据库和 0.2.1 应用归档，
补回新书注册项时仅追加缺失项，不恢复整个旧数据库，保留用户刚产生的学习记录。
